here so that the TikTok for Developers app registration can link to publicly reachable
Terms of Service and Privacy Policy URLs.

- [Terms of Service](terms-of-service.md)
- [Privacy Policy](privacy-policy.md)

## About the application

Shorts uploader is a **local desktop tool**. It runs on the user's own computer and uses the
user's own API credentials to turn long YouTube videos into vertical Shorts and upload them
to the user's YouTube channel and TikTok drafts.

- There is no hosted service and no server operated by the author.
- There are no accounts with the author, no analytics and no telemetry.
- Credentials and history are stored locally on the user's machine.

The application's source code is not published in this repository. This repository contains
only the policy documents.
